u -> user
g -> group 
o -> others

drwxrwxrwx  -> here we can have three sections from right to left 
here d -> represent this is directory 

1. rwx ( first section) -> This is for user level permissions
2.    rwx ( second section) -> This is for group level permissions
3.       rwx (third section) -> This is for other level permissions

r -> read access 
w -> write acess 
x -> execute access
- -> no permissions

How add permissions
u+w , g+w , o+w

How remove permissions
u-w , g-w , o-w

How change file permissions -> command 
chmod section+permissions file_name.extension
ex -> chmode o+w file.txt

We can use symbolic mode to work with file permissions

0 ------------> No Permissions
1 ------------> Execute
2 ------------> Write 
3 ------------> Execute & Write
4 ------------> Read
5 ------------> Read & Execute
6 ------------> Read & Write
7 ------------>Read, Write & Execute
